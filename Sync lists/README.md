## 📄 Sync To-Do Lists

**Файл:** `sync_lists_manual.yaml`

Blueprint для ручной синхронизации активных пунктов между двумя To-do списками.

### Входные параметры

| Параметр | Описание | Обязательный |
|----------|----------|:------------:|
| `source_list` | Исходный To-do список (откуда копировать) | ✅ |
| `target_list` | Целевой To-do список (куда копировать) | ✅ |
| `full_sync` | Режим синхронизации: `false` — только добавление новых, `true` — полная двусторонняя синхронизация (добавление + удаление) | ❌ (по умолч. `false`) |

### Режимы работы

#### Режим 1: Добавление новых (full_sync = false)
- Все активные пункты из исходного списка, отсутствующие в целевом, добавляются в целевой список
- Существующие пункты в целевом списке **не удаляются**

#### Режим 2: Полная синхронизация (full_sync = true)
- Все активные пункты из исходного списка, отсутствующие в целевом, **добавляются** в целевой список
- Все пункты в целевом списке, отсутствующие в исходном, **удаляются** из целевого
- В результате целевой список становится точной копией исходного (по активным пунктам)

### Как это работает

1. Получает активные пункты из обоих списков через сервис `todo.get_items`
2. Сравнивает пункты по UID (уникальному идентификатору)
3. **Добавление:** пункты из исходного списка, которых нет в целевом, добавляются через `todo.add_item`
4. **Удаление (full_sync):** пункты из целевого списка, которых нет в исходном, удаляются через `todo.remove_item`

### Установка

1. Импортируйте blueprint в Home Assistant: **Настройки → Автоматизации → Blueprints → Импорт**
2. Создайте скрипт на основе blueprint'а
3. Укажите исходный и целевой To-do списки
4. При необходимости включите режим полной синхронизации

### Требования

- Home Assistant **2025.12+**
- Сущности **todo** (сервисы `todo.get_items`, `todo.add_item`, `todo.remove_item`)
