## 📄 Push updates to Telegram

**Файл:** `push_todo_to_telegram.yaml`

Автоматизация отслеживает изменения сущности `todo` в Home Assistant и отправляет актуальный список покупок в Telegram с inline-кнопками.

### Как это работает

1. Автоматизация срабатывает при изменении состояния указанной `todo`-сущности
2. Фильтрует события — реагирует только на изменения, **не** инициированные самим blueprint (чтобы избежать зацикливания)
3. Запрашивает активные пункты через сервис `todo.get_items`
4. Формирует сообщение и inline-клавиатуру с кнопками:
   - `✅` — отметить выполненным
   - `📂 Все` — показать все пункты
   - `🗑 Очистить` — удалить выполненные
5. Отправляет сообщение в Telegram через `telegram_bot.send_message`

### Настройка

1. Укажите сущность `todo` в `triggers[].entity_id`
2. Укажите `config_entry_id` и `chat_id` вашего Telegram-бота в действии `telegram_bot.send_message`

### Требования

- Home Assistant **2025.12+**
- Интеграция **Telegram Bot** (настроенная с известным Config Entry ID)
- Сущность **todo** (сервисы `todo.get_items`)
