# Changelog

Все значимые изменения проекта **Telegram To-do List TEST** фиксируются в этом файле.

Формат основан на принципах *Keep a Changelog*.
Версионирование — произвольное (не обязательно SemVer), так как проект — blueprint для Home Assistant.

---

## [Unreleased]

### Added

- Кнопка импорта blueprint в README (один клик для установки в Home Assistant)
- Кнопка чаевых (CloudTips) в README
- Отдельный **режим редактирования списка** через кнопку `✏️ Редактировать`
- Переключение отметки `✨` у пунктов списка без использования helper
- Отдельная inline-кнопка для каждого пункта в режиме редактирования
- Кнопка `✍️ Закончить` для выхода из режима редактирования

### Changed

- Пункты с `✨` автоматически отображаются **вверху списка**
- При повторном нажатии на пункт в режиме редактирования `✨` удаляется
- После завершения редактирования список возвращается в обычный режим
- Сортировка `✨` применяется при отображении активных пунктов и после обновления списка

### Fixed

- Удаление `✨` выполняется напрямую через `summary[:-1]`, без `regex_replace`
- Сохранён UID каждого todo-пункта при редактировании, поэтому изменение `✨` не создаёт новый пункт

## [1.2.0] - 2026-07-28

### Added

- Поддержка до **3 скриптов синхронизации** (`sync_script_1`, `sync_script_2`, `sync_script_3`)
- Кнопка `🗳️ Скрипты` в reply-клавиатуре (выпадающее меню выбора скрипта)
- Inline-кнопки скриптов после каждого обновления списка
- Настраиваемые названия кнопок скриптов (`sync_script_1_name`, `sync_script_2_name`, `sync_script_3_name`)

### Fixed

- Исправлены ссылки на `bot_config_entry_id` в conditions шаблона значения

### Changed

- Переименованы кнопки синхронизации для единообразия
- Структура репозитория реорганизована:
  - `telegram-todo-list-ru/` — отдельная папка с blueprint и документацией
  - `Sync lists/` — скрипты синхронизации
  - `automations/` — автоматизации
  - Корневой `README.md` с обзором всех проектов

## [1.1.0] - 2026-01-13

### Added

- Reply-клавиатура с быстрыми действиями:
  - 📋 Показать список
  - 🗑 Очистить выполненные
- Reply-клавиатура отображается только при команде `/start`

### Changed

- Reply-действия обрабатываются отдельно от inline-кнопок через `telegram_text`
- Reply-кнопки не добавляют элементы в список покупок
- Reply-кнопка «Очистить выполненные» использует существующую логику `clear_completed` и отправляет обновлённый список

### Unchanged

- Логика inline-кнопок (`edit_message`)
- Переключение режимов Active / All
- Динамическое отображение кнопок «Все / Активные / Очистить»
- Защита от дублей и логика `reopen` по ☑️

---

## [1.0.0] - 2026-01-13

### Added

- Управление To-do списком через Telegram
- Inline-кнопки для:
  - отметки пунктов как выполненных
  - возврата выполненных пунктов в активные
- Переключение отображения Active / All
- Динамическая кнопка «Очистить выполненные»
- Защита от дублей при добавлении пунктов:
  - сравнение без учёта регистра и пробелов
  - повторная активация выполненных пунктов
- Обновление сообщения через `edit_message` без лишних отправок

### Notes

- Blueprint рассчитан на Home Assistant 2025.12+
- Логика inline и reply-кнопок разделена намеренно
