# 🛒 Telegram To-do List для Home Assistant

> Управление списком покупок/дел через Telegram-бота с inline-кнопками и reply-клавиатурой.

## Описание

Blueprint для Home Assistant, который превращает сущность `todo` в удобный Telegram-бот для списков. Пользователь добавляет пункты текстом, управляет списком кнопками — бот мгновенно обновляет сообщение через `edit_message`.

### Возможности

- **Добавление пунктов** — просто напишите в чат: `молоко, хлеб, яйца` (через запятую или точку)
- **Inline-кнопки** — `✅` отметить выполненным, `☑️` вернуть в активные, `🗑` очистить выполненные
- **Переключение режимов** — «Активные» / «Все» (кнопки появляются только когда есть выполненные)
- **Reply-клавиатура** — `📋 Показать список`, `🗑 Очистить выполненные`, `🗳️ Скрипты`
- **Защита от дублей** — повторное добавление существующего пункта покажет предупреждение
- **Reopen** — выполненный пункт можно вернуть нажатием `☑️`
- **Синхронизация** — до 3 скриптов для внешней синхронизации (опционально)
- **Фильтрация** — бот реагирует только на события от указанного бота и чата

## Требования

- Home Assistant **2025.12+**
- Настроенный Telegram-бот с известным **Config Entry ID**
- Сущность `todo` (например `todo.shopping_list`)

## Входные параметры

| Параметр | Описание | Обязательный |
|----------|----------|:------------:|
| `todo_entity` | Сущность To-do списка | ✅ |
| `telegram_chat_id` | ID чата Telegram | ✅ |
| `bot_config_entry_id` | Config Entry ID бота | ✅ |
| `sync_script_1` | Скрипт синхронизации 1 | ❌ |
| `sync_script_1_name` | Название кнопки скрипта 1 | ❌ |
| `sync_script_2` | Скрипт синхронизации 2 | ❌ |
| `sync_script_2_name` | Название кнопки скрипта 2 | ❌ |
| `sync_script_3` | Скрипт синхронизации 3 | ❌ |
| `sync_script_3_name` | Название кнопки скрипта 3 | ❌ |

## Установка

1. Импортируйте blueprint в Home Assistant (Настройки → Автоматизации → Blueprints → Импорт)
2. Создайте автоматизацию на основе blueprint
3. Укажите параметры: `todo_entity`, `telegram_chat_id`, `bot_config_entry_id`
4. (Опционально) Укажите скрипты синхронизации

## Команды

| Команда / Кнопка | Действие |
|-------------------|----------|
| `/start` | Показать reply-клавиатуру |
| `/list` | Показать активные пункты |
| `/done_{uid}` | Отметить пункт выполненным |
| `/reopen_{uid}` | Вернуть выполненный пункт |
| `/show_all` | Показать все пункты (активные + выполненные) |
| `/show_active` | Показать только активные |
| `/clear_completed` | Удалить все выполненные |
| `/sync_1`, `/sync_2`, `/sync_3` | Запустить скрипт синхронизации |

## Как это работает

```
Пользователь → Telegram → Blueprint → Home Assistant (todo) → Telegram → Пользователь
```

1. Blueprint слушает события `telegram_command`, `telegram_text`, `telegram_callback`
2. Фильтрует по `chat_id` и `config_entry_id` — реагирует только на нужного бота в нужном чате
3. Текстовые сообщения парсятся на пункты (разделители: `,` и `.`)
4. Каждый пункт проверяется на дубликаты (без учёта регистра и пробелов)
5. Inline-кнопки обновляются через `edit_message` — сообщение перезаписывается, а не отправляется заново

## Пример использования

### Быстрый старт через Панель разработчика

Отправьте в чат команду через Действия (Developer Tools → Actions):

```yaml
action: telegram_bot.send_message
data:
  config_entry_id: "ВАШ_CONFIG_ENTRY_ID"
  chat_id: "ВАШ_CHAT_ID"
  message: "Используй кнопки внизу ⬇️"
  keyboard:
    - "📋 Показать список"
    - "🗑 Очистить выполненные"
    - "🗳️ Скрипты"
  resize_keyboard: true
  one_time_keyboard: false
```

### Синхронизация с внешним списком

Blueprint поддерживает до 3 скриптов синхронизации. Кнопки скриптов появляются:
- В reply-клавиатуре (если хотя бы один скрипт настроен)
- В inline-клавиатуре после каждого обновления списка
- Отдельным меню по кнопке `🗳️ Скрипты`
